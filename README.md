# 像素撤离 / PIXEL EXTRACT

纯前端单机像素风搜打撤小游戏。无需安装依赖、无需联网，打开 index.html 即可游玩。

## 快速开始

- 双击 启动游戏.bat，或直接双击 index.html。
- 如果浏览器限制本地存档，可在当前目录运行：python -m http.server 8080，然后访问 http://localhost:8080。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 移动 |
| 鼠标 | 瞄准 |
| 左键 | 射击 |

| Esc | 暂停 / 继续 |

## 已实现内容

- 更大的 72×54 随机房间 + 走廊地图，每层生成 13-18 个房间，每局重新生成
- 单机俯视角战斗：像素角色、弹道、粒子、屏幕震动
- AI 敌人：巡逻、发现玩家、追击、射击
- 搜刮补给箱，随机获得废料、电子件、遗物、核心、武器、护甲和背包装备等收集品；击杀敌人有概率掉落强化石
- 新增纤维束、废旧电路、高能电池、光学镜片、无人机核心、战地勋章、量子存储器、相位遗物等收集品
- 补给箱按普通/高级/钥匙房分档，品质越高越容易出稀有和史诗物品；楼层越深、风险越高，高品质权重越高
- 独立背包装备槽、动态背包容量、武器/护甲/背包强化、蜕变永久成长、医疗包、弹药和地面掉落
- 绿色撤离点，停留 3 秒后选择继续下一层或返回基地结算
- 死亡损失携带物资，撤离后物资进入仓库
- 仓库、装备栏、武器/护甲/背包属性；整备中心提供装备、仓库、黑市、强化、蜕变五个独立窗口
- 手机横屏一屏布局：基地为作战准备和整备中心两栏，五个整备窗口无需上下滚动，黑市商品使用双列紧凑展示
- 基地不显示等级或经验；本局等级、经验和成长只在行动中生效
- 黑市购买武器、护甲和永久补给升级
- 本地自动存档（localStorage，键名 pixel_extract_save_v1），支持导出/导入存档码
- 纯 Canvas 绘制，没有外部图片、音频或网络依赖
- 三档行动风险：普通 / 危险 / 极限，敌人数量、血量和掉落品质不同
- 地图变大后同步增加房间、补给箱和敌人数量，并提高高级补给箱的可见度（青色光效/地图标记）
- 随机行动事件：精英巡逻队、临时撤离点、区域断电
- 首领每 5 层出现一次；首领层使用独立血条并掉落专属武器
- 钥匙守卫掉落 🔑；每层钥匙房内有一个需要钥匙开启的高价值宝箱
- 战争迷雾：未探索区域隐藏，走过的路径会保留在战术地图上
- 敌人开火前有红色蓄力提示；首领和精英更明显
- 背包自动按武器/护甲/背包/强化石/物资和品质整理，装备会显示与当前装备的强弱对比
- 仓库支持品质筛选和一键出售普通物资
- 小地图下方显示首领状态、最近可见敌人距离和交火数量
- 设置中可调瞄准圈大小、瞄准灵敏度，并开启性能模式
- 首次行动显示四步教学：移动、搜索、战斗、撤离，可随时跳过，完成或跳过后不再出现
- 战斗反馈包含命中准星、击杀提示、受击方向指示和低血量屏幕脉冲
- 行动中击杀、搜刮可获得经验；升级后从 3 项随机强化中选择 1 项本局成长
- 撤离点可继续下一层：保留本局等级、成长和背包，敌人和稀有掉落随层数提升

## 手机游玩

- 手机浏览器可以直接打开，建议横屏。
- 移动摇杆可在设置中切换浮动/固定，并可调整摇杆大小、左侧触发区域和移动灵敏度。
- 移动输入加入小死区与速度平滑，并减少拖动时的高频布局读取，降低偶发卡顿。
- 轻触右侧瞄准区只调整方向，长按约 0.15 秒后开火，避免想观察时误射。
- 自动索敌：手机按住瞄准区时，直接锁定武器射程内最近的可见敌人，不受人物朝向限制，倒退移动时也能自动转身开火；桌面端按住开火时锁定前方 75° 内最近的可见敌人。HUD 会显示「索敌 ON / 锁定」。可在「设置 → 触控 → 自动索敌」关闭。
- 全自动射击：长按右侧瞄准区持续开火，拖动瞄准区即可调整方向；触屏下所有武器都会连射。
- 搜索补给箱：靠近补给箱并站定 2 秒自动搜索，不需要按 E；移动、受伤或换弹会打断，离开范围会清空进度。金色钥匙箱需要先消耗 1 把钥匙。
- 瞄准圈大小和灵敏度可在「设置 → 触控」中调整。
- 撤离点停留 3 秒后选择继续下一层或返回基地。另有换弹、医疗、背包、地图和暂停按钮。
- 地图受战争迷雾限制，只显示探索过的区域和走过的路径；钥匙箱、可见敌人和已发现首领会显示在地图上。
- 手机端会自动显示触屏控件，并隐藏桌面键鼠提示。

### 用手机打开

1. 手机和电脑连接同一个 Wi-Fi。
2. 双击 启动手机版.bat。
3. 在窗口中找到电脑的 IPv4 地址，手机浏览器访问 http://那个地址:8080/index.html。
4. 如果打不开，检查 Windows 防火墙是否允许 Python 或本地网络访问。

## 整备中心

- 回到基地后，在「整备中心」分别点击装备、仓库、黑市、强化、蜕变卡片。
- 五个功能各自打开独立窗口，不再使用页签，也不再有额外的整备窗口入口。
- 装备窗口会显示当前武器/护甲/背包装备和仓库中可替换的装备，点击对应物品的 装备 按钮即可替换。
- 护甲和背包装备都可以点击 卸下 放回仓库。
- 强化窗口会显示当前武器/护甲/背包装备、强化等级和强化石列表。
- 蜕变窗口会显示当前蜕变等级、价值进度、下一阶段需求和永久属性加成。
- 行动中不能更换装备，避免战斗中途刷属性。

## 装备库扩充

- 武器新增：破门霰弹枪、铁皮轻机枪、磁轨手枪。
- 护甲新增：侦察背心、战地医疗甲、幽灵纤维甲。
- 这些装备已经加入黑市和稀有补给箱掉落池。
- 破门霰弹枪一次发射 6 枚弹丸；侦察背心提供移速，战地医疗甲额外提供医疗包，幽灵纤维甲降低敌人视野。

## 背包装备

- 新增独立背包装备槽，基础容量为 8 格，背包品质会额外提供容量。
- 白色品质 +8、绿色品质 +16、蓝色品质 +24、紫色品质 +32、红色品质 +40、彩色品质 +50。
- 实际容量 = 基础 8 格 + 背包装备加成 + 本局「扩容背包」成长。
- 普通补给箱、高级补给箱和钥匙房宝箱都有概率掉落背包；宝箱品质越高，越容易出高品级背包。
- 装备、替换或卸下背包只能在基地整备中心进行；行动中打开背包可查看当前背包装备和容量占用。

## 强化系统

- 击杀敌人有概率掉落强化石：普通敌人约 10%，精英/守卫约 28%，首领必定掉落 1 颗；危险和极限风险会提高掉落概率。
- 强化石分六档品质和等级：白色 Lv.1 成功率 30%、绿色 Lv.2 45%、蓝色 Lv.3 60%、紫色 Lv.4 75%、红色 Lv.5 90%、彩色 Lv.6 100%。
- 楼层越深、风险越高，掉落的强化石品质越好；强化石会作为物品进入背包，撤离后存入仓库。
- 在基地「整备中心 → 强化」中选择已装备的武器、护甲或背包，再选择一颗强化石进行强化。
- 强化等级上限为 +10。成功提升 1 级，失败消耗 1 颗强化石但不会降级。
- 每级强化效果：武器伤害 +5%，护甲伤害减免 +1.5%，背包容量 +1 格。
- 强化效果会显示在作战准备、装备窗口、行动 HUD 和战术背包详情中；强化等级会随装备一起保存。

## 蜕变系统

- 基地「整备中心 → 蜕变」可将仓库物品投入蜕变熔炉，按物品出售价值增加蜕变进度。
- 第一次蜕变需要 1000 价值；之后每次需求约为上一次的 1.25 倍（按整数向上取整），当前需求会直接显示在进度条上方。
- 可以逐件转化仓库物品，也可以一键转化普通/精良品质的普通物资；转化会消耗物品。
- 进度达到需求后点击「蜕变」，消耗对应进度并永久提升角色属性；多余进度会保留到下一阶段。
- 每次蜕变的永久加成：最大生命 +10、武器伤害 +2%、伤害减免 +1%、移动速度 +1%。
- 蜕变等级、进度和永久加成会自动保存，并作用于之后的所有行动；行动中打开战术背包可查看当前蜕变等级和属性。

## 行动中打开背包

- 电脑端可以点击游戏画面左下角的 打开背包 按钮。
- 也可以直接按 Tab 打开或关闭背包。
- 手机端使用右侧的 背包 按钮。

## 掉落品质与收集品

- 普通补给箱的基础品质权重约为：普通 62%、精良 27%、稀有 9%、史诗 2%。
- 高级补给箱的基础品质权重约为：普通 26%、精良 34%、稀有 29%、史诗 11%，并会掉落 2-4 件物品。
- 钥匙房宝箱不会出普通物品：精良约 18%、稀有约 52%、史诗约 30%，固定掉落 4-5 件，并至少保证一件稀有或史诗。
- 每深入一层，稀有和史诗权重会提高；危险/极限难度会额外提高高品质爆率。
- 普通收集品分为普通、精良、稀有、史诗四档，品质越高单价越高；背包装备和强化石另有传说（红色）和神话（彩色）品质，并会进入仓库品质筛选。
- 背包装备掉落独立于普通物资池：普通箱约 5%、高级箱约 16%、钥匙房宝箱约 55% 概率出现；高品级背包在深层和更高风险行动中更容易出现。
- 强化石不占普通物资掉落池，只由敌人死亡掉落；白色到彩色六档分别对应 Lv.1 到 Lv.6 的强化成功率。

## 地图、迷雾与撤离

- 小地图和完整地图只显示已探索区域；未探索区域被战争迷雾覆盖。
- 玩家走过的路径会以青色轨迹保留在地图上，方便折返和规划路线。
- 未搜索补给箱、金色钥匙房宝箱、可见敌人、已发现首领和撤离点会显示在地图上。
- 下方情报栏显示首领状态、最近可见敌人距离和交火数量；首领未进入视野时不会暴露位置。
- 按 M 或点击小地图下方的 打开地图 按钮，可以查看完整战术地图。
- 进入撤离区域后，停留 3 秒会打开选择：继续下一层，或返回基地结算。
- 离开撤离区域会重置读秒；继续下一层会保留本局等级、成长、钥匙和背包。

## 背包物品详情

- 行动中点击 打开背包 或按 Tab 后，会显示当前武器、护甲、背包装备、弹药、医疗包、背包占用和携带估值。
- 点击任意搜刮物品，可以在右侧详情区查看名称、稀有度、类型、数量、说明和估值。
- 武器会显示伤害、弹匣、射速、射击模式和备弹；护甲会显示减伤和特殊加成。
- 手机端详情区会显示在物品列表旁边，可上下滚动查看完整属性。

## 首领、钥匙与专属武器

- 首领只在第 5、10、15……层出现，普通楼层不会刷新首领。
- 首领层会在远离出生点的大型房间刷新首领「终焉守卫」；进入视野后完整地图才会显示红色菱形标记。
- 靠近首领或与其交火后，屏幕顶部会出现首领专属血条。
- 首领使用高伤害散射能量弹，血量会随楼层提升。
- 击败首领后必掉专属武器「终焉协议」；靠近会自动拾取，背包满时武器会留在地上。
- 每层都有一名金色「钥匙守卫」，击倒后掉落 🔑；拾取后可在同层钥匙房开启高价值宝箱。
- 钥匙箱会消耗 1 把钥匙，提供 4-5 件高品质物资，并有额外弹药和医疗包。
- 「终焉协议」为双弹丸全自动武器：伤害 30、弹匣 24、备弹 144，只能通过击败首领获得。
- 携带该武器成功撤离后会进入仓库，可在基地「整备中心」的装备窗口中装备。

## 不依赖局域网的玩法

游戏本体是纯静态网页，不需要后端。把整个目录部署到任意静态网站后，手机用流量或任意 Wi-Fi 都能打开。

- 已加入 PWA 支持：`manifest.webmanifest`、图标和 `sw.js` 离线缓存。
- 首次通过公网地址打开后，可以添加到手机主屏幕；之后断网也能启动。
- 单文件离线版：`像素撤离-离线版.html`，电脑双击即可游玩，Android 浏览器也可直接打开。
- iPhone 对本地 HTML 文件限制较多，推荐使用公网静态托管并添加到主屏幕。
- 公网地址与局域网地址属于不同来源，两边的 `localStorage` 存档不会自动互通。

详细部署步骤见 `部署说明.md`。

- 主菜单和暂停菜单新增「横屏全屏」按钮。
- 主菜单和暂停菜单新增「设置」按钮。
- 设置项包括：音效、屏幕震动、浮动文字、受伤红屏；触控页还可调整自动索敌、摇杆模式、摇杆大小、移动触发区域和移动灵敏度。
- 设置会自动保存到本地存档。

## 行动风险与随机事件

- 开始行动前可在作战准备面板选择「普通 / 危险 / 极限」。
- 风险越高，敌人越多、血量与伤害越高，稀有补给箱概率也越高。
- 每局有概率触发随机事件：精英巡逻队、临时撤离点或区域断电。
- 临时撤离点会在 75 秒后关闭；区域断电会降低视野 35 秒。
- 金色钥匙守卫和钥匙房宝箱会在地图上用金色标记；精英敌人会显示金色外圈。

## 本局等级与连续下层

- 主界面不再保留等级、经验或永久成长，每次开始行动都从 LV.1 重新开始。
- 击杀敌人和搜刮物资会获得本局经验；升级后暂停战斗，从 3 项随机强化中选择 1 项。
- 可强化最大生命、移动速度、换弹速度、背包容量、伤害减免、备弹量、医疗包和获取经验。
- 每项强化都有本局等级上限；所有强化满级后，多余升级会转化为最大生命。
- 到达撤离点并停留 3 秒后，可以选择「继续下一层」或「返回基地」。
- 继续下一层会保留当前生命、弹药、医疗包、背包、等级和成长，但敌人血量、伤害、数量以及稀有物资概率会随楼层提高。
- 返回基地会结算并带回背包物资；死亡会丢失本局等级、成长和所有携带物资。

## 存档备份

- 设置 → 基础 → 导出存档：把存档码复制到备忘录或发给自己。
- 设置 → 基础 → 导入存档：粘贴存档码即可恢复。导入会覆盖当前存档。
