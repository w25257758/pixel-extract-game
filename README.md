# 像素撤离 / PIXEL EXTRACT

纯前端单机像素风搜打撤小游戏。无需安装依赖、无需联网，打开 index.html 即可游玩。

## 快速开始

- 双击 启动游戏.bat，或直接双击 index.html。
- 如果浏览器限制本地存档，可在当前目录运行：python -m http.server 8080，然后访问 http://localhost:8080。

| 鼠标 | 瞄准 |

## 已实现内容

- 随机房间 + 走廊地图，每局重新生成
- 单机俯视角战斗：像素角色、弹道、粒子、屏幕震动
- AI 敌人：巡逻、发现玩家、追击、射击
- 搜刮补给箱，随机获得废料、芯片、遗物、核心、武器、护甲
- 背包容量、医疗包、弹药和地面掉落
- 绿色撤离点，进入后停留 3 秒自动撤离
- 死亡损失携带物资，撤离后物资进入仓库
- 仓库、装备栏、武器/护甲属性
- 等级、经验、生命上限、背包容量成长
- 黑市购买武器、护甲和永久补给升级
- 本地自动存档（localStorage，键名 pixel_extract_save_v1）
- 纯 Canvas 绘制，没有外部图片、音频或网络依赖

## 说明

- 这是单机版本，不包含联机、账号、匹配和服务器。
- 像素图形与音效为程序化生成，避免外部素材授权问题。
- 想继续扩展时，优先从 js/game.js 里的 ITEM_DEFS、SHOP、Enemy 和 generateWorld 入手。

## 手机游玩

- 手机浏览器可以直接打开，建议横屏。
- 移动摇杆可在设置中切换浮动/固定，并可调整摇杆大小、左侧触发区域和移动灵敏度。
- 射击自动锁定：按住右侧瞄准区开火时，自动瞄准最近的可见敌人；可在「设置 → 触控 → 自动锁定」关闭。
- 全自动射击：按住右侧瞄准区持续开火，拖动瞄准区即可调整方向；触屏下所有武器都会连射。
- 搜索补给箱：靠近补给箱并停留 2 秒即可自动搜索，不需要按 E。
- 撤离点停留 3 秒自动撤离。另有换弹、医疗、背包、地图和暂停按钮。
- 手机端会自动显示触屏控件，并隐藏桌面键鼠提示。

### 用手机打开

1. 手机和电脑连接同一个 Wi-Fi。
2. 双击 启动手机版.bat。
3. 在窗口中找到电脑的 IPv4 地址，手机浏览器访问 http://那个地址:8080/index.html。
4. 如果打不开，检查 Windows 防火墙是否允许 Python 或本地网络访问。

## 更换装备

- 回到基地后，在作战准备面板点击 更换装备。
- 武器和护甲会分栏显示，点击对应物品的 装备 按钮即可替换。
- 护甲可以点击 卸下 放回仓库。
- 行动中不能更换装备，避免战斗中途刷属性。

## 装备库扩充

- 武器新增：破门霰弹枪、铁皮轻机枪、磁轨手枪。
- 护甲新增：侦察背心、战地医疗甲、幽灵纤维甲。
- 这些装备已经加入黑市和稀有补给箱掉落池。
- 破门霰弹枪一次发射 6 枚弹丸；侦察背心提供移速，战地医疗甲额外提供医疗包，幽灵纤维甲降低敌人视野。

## 行动中打开背包

- 电脑端可以点击游戏画面左下角的 打开背包 按钮。
- 也可以直接按 Tab 打开或关闭背包。
- 手机端使用右侧的 背包 按钮。

## 地图与撤离

- 小地图会持续显示地形、玩家方向、未搜索补给箱和撤离点。
- 按 M 或点击小地图下方的 打开地图 按钮，可以查看完整战术地图。
- 完整地图会用绿色圆环和 撤离点 文字标记撤离位置。
- 进入撤离区域后，停留 3 秒即可自动撤离，不需要按 E。
- 离开撤离区域会重置读秒。

## 背包物品详情

- 行动中点击 打开背包 或按 Tab 后，会显示当前武器、护甲、弹药、医疗包、背包占用和携带估值。
- 点击任意搜刮物品，可以在右侧详情区查看名称、稀有度、类型、数量、说明和估值。
- 武器会显示伤害、弹匣、射速、射击模式和备弹；护甲会显示减伤和特殊加成。
- 手机端详情区会显示在物品列表旁边，可上下滚动查看完整属性。

## 首领与专属武器

- 每局会在远离出生点的大型房间刷新首领「终焉守卫」，完整地图上用红色菱形标记。
- 靠近首领或与其交火后，屏幕顶部会出现首领专属血条。
- 首领使用高伤害散射能量弹，血量会随玩家等级成长。
- 击败首领后必掉专属武器「终焉协议」；靠近会自动拾取，背包满时武器会留在地上。
- 「终焉协议」为双弹丸全自动武器：伤害 30、弹匣 24、备弹 144，只能通过击败首领获得。
- 携带该武器成功撤离后会进入仓库，可在基地的「更换装备」中装备。

## 不依赖局域网的玩法

游戏本体是纯静态网页，不需要后端。把整个目录部署到任意静态网站后，手机用流量或任意 Wi-Fi 都能打开。

- 已加入 PWA 支持：`manifest.webmanifest`、图标和 `sw.js` 离线缓存。
- 首次通过公网地址打开后，可以添加到手机主屏幕；之后断网也能启动。
- 单文件离线版：`像素撤离-离线版.html`，电脑双击即可游玩，Android 浏览器也可直接打开。
- iPhone 对本地 HTML 文件限制较多，推荐使用公网静态托管并添加到主屏幕。
- 公网地址与局域网地址属于不同来源，两边的 `localStorage` 存档不会自动互通。

详细部署步骤见 `部署说明.md`。

## 横屏全屏与设置

- 主菜单和暂停菜单新增「横屏全屏」按钮。
- 主菜单和暂停菜单新增「设置」按钮。
- 设置项包括：音效、屏幕震动、浮动文字、受伤红屏；触控页还可调整自动锁定、摇杆模式、摇杆大小、移动触发区域和移动灵敏度。
- 设置会自动保存到本地存档。
- 手机竖屏开始行动时会尝试进入全屏并锁定横屏；若浏览器不支持，请开启系统自动旋转，或把游戏添加到主屏幕后从图标启动。
